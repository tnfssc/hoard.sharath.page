# Values

## Keep the change close to the ask

A logo change should fix the mark, not redo the app. Keep the asset paths when they already work. This helps with small visual changes. It does not rule out a wider rebuild when the user asks for one. See [brand notes](brand.md).

## Check what the user reaches

A successful build is not the same as a live update. After deployment, check the public route and the actual served files. This helps with proxy and cache paths. It does not replace app tests. See [deployment notes](deployment.md).
